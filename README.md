# Kaleido Launcher

An OBS Studio plugin that starts and stops the apps you use for streaming. Configure the list once, then launch everything with OBS — or from **KaleidoVR → App Autostarter** in the top menu bar.

<img width="462" height="652" alt="Kaleido Launcher" src="https://github.com/user-attachments/assets/7e9ac50b-f988-4ead-a79e-74a2ba2939ba" />

## Features
- **Automatic startup** — Launch your apps when OBS starts
- **Profiles** — Separate lists for different streams or setups
- **Launch minimized** — Per-app option to start in the background
- **Close on exit** — Optionally close those apps when OBS quits
- **Scene collections** — Save the launcher config with the collection
- **Backup** — Export and import settings as JSON

## Install
Windows x64. Designed for **OBS Studio 32.2.2**.

**Installer** — run [KaleidoLauncher_Installer.exe](https://github.com/KaleidoVR/Kaleido-Launcher/releases/latest). It installs into your 64-bit OBS folder.

**ZIP** — extract [kaleido-launcher-win64.zip](https://github.com/KaleidoVR/Kaleido-Launcher/releases/latest) over `C:\Program Files\obs-studio`. The archive opens at `obs-plugins`.

Restart OBS, then open **KaleidoVR → App Autostarter** in the top menu bar.
